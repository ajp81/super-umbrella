# Contributing

This repository is currently in its early setup phase. Contributions are welcome once the project direction and conventions are established.

## Current expectations

- Keep changes focused and easy to review.
- Prefer small, well-scoped pull requests.
- Document non-obvious decisions in the PR description.
- If you plan a larger change, open or reference an issue first.

## Before you open a pull request

1. Check the current repository state and any open issues.
2. Keep the scope narrow and clearly described.
3. Add or update tests for behavior changes when applicable.
4. Ensure the change is consistent with the repository's existing conventions.

## Questions

If you are unsure whether a contribution fits, open an issue before starting work.
